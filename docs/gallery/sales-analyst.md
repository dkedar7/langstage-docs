**Stage:** the web app, `langstage`. **Shows:** a persistent Python session, Plotly
charts in the chat, and a written report built on the Canvas.

Ask a question about your data, get the answer with the work shown. This example is
the analyst's loop: load the data, slice it until the change is explained, chart what
matters, and write it up somewhere a colleague can read it.

## What happens

1. With the **Canvas** open, you ask: "What drove Q3 revenue, and is there anything I
   should worry about? Put the findings on the canvas."
2. The agent loads `sales.csv`, a year of weekly sales, in a Python session that
   persists between calls, and compares Q3 with Q2 by category, channel and region.
3. It charts what it finds with Plotly. Each chart appears in the chat as it's made,
   and goes on the Canvas with a short paragraph explaining it.
4. The answer: Q3 revenue was up 12.4% on Q2, mostly apparel (+56.5%) and the online
   channel. The worry: footwear is the one category that shrank, and its return rate
   went up. Broken down by region, the rise is almost all the **Northeast**, where
   August and September returns spiked. The agent calls it a likely product or sizing
   issue and says to pull SKU-level data next.
5. The Canvas ends up as a short report with an overview, the drivers, the concern and
   a conclusion, which you can export as Markdown.

## The agent

83 lines in [`gallery/sales-analyst/agent.py`](https://github.com/dkedar7/langstage-docs/blob/main/gallery/sales-analyst/agent.py),
and most of them are the prompt. It's a plain `create_agent(...)` built from parts the
`langstage` package provides:

- **`run_python`**, a five-line tool around LangStage's notebook session
  (`create_cell` + `execute_cell`). Variables and DataFrames persist between calls,
  like cells in a notebook.
- **`display_inline`**, which renders a chart, table or image file in the chat.
- **`CanvasMiddleware`**, which gives the agent the Canvas tools and tells it how to
  build a report with sections, narrative and a conclusion.
- **`.with_config(recursion_limit=80)`**. An analysis plus a report takes more than
  LangGraph's default 25 steps.

## Run it yourself

<!-- snippet: check -->
```bash
git clone https://github.com/dkedar7/langstage-docs
cd langstage-docs/gallery/sales-analyst
pip install langstage langchain-anthropic pandas plotly
export ANTHROPIC_API_KEY=...
langstage run --agent agent.py:graph --workspace workspace
```

Open the **Canvas** tab and ask your question. To use OpenRouter instead, set
`OPENROUTER_API_KEY` and `pip install langchain-openai`.

The data is synthetic, generated by
[`make_data.py`](https://github.com/dkedar7/langstage-docs/blob/main/gallery/sales-analyst/make_data.py)
from a fixed seed. It has the patterns real retail data has, for the agent to find on
its own: seasonal camping and apparel peaks, a growing online share, one region
growing faster than the rest, and a footwear sizing problem in one region. Point the
agent at your own CSV by changing the first paragraph of its prompt.
