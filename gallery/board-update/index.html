    Board update with suggestions¶

    Stage: Documents, langstage-codraft. Shows: your own agent co-authoring a document, suggestions you accept, a comment the agent acts on, and a checkpoint that shows what changed since.

    A quarterly update goes through several hands. Someone drafts it from the numbers, finance checks the figures, and the board reads the final version. This example is that loop on one page. The authors write the outline and the ask. The agent drafts the sections in between from the data, and changes nothing without the authors' yes.

    What happens¶

    1. The document holds the authors' outline: an opening, headings for Results and Returns, and the ask, $120,000 for a tent-pole fix.
    2. You ask the agent, Juniper, to "draft a short paragraph under Results and one under Returns from the Q3 numbers and the ops notes." It reads the metrics and the notes, works out each percentage change with a tool rather than guessing, and proposes both paragraphs. They wait on the page as suggested blocks. The return rate is marked preliminary, as the data says.
    3. You accept both, then save a checkpoint called Sent to finance.
    4. Finance closes the books and corrects the return rate from 6.4% to 7.1%. You leave that as a comment on the Returns paragraph and click Address all comments. The agent proposes an edit that changes the figure, drops "preliminary", and leaves the rest alone. You read the diff and accept it.
    5. Document → Checkpoints → 1 change since… shows exactly what changed since the version finance saw: one paragraph, as a word diff. Export redline turns the same diff into a Word file with tracked changes.

    The agent¶

    94 lines in gallery/board-update/agent.py. The parts that matter:

    • Your tools, next to Codraft's. read_metrics and read_ops_notes read the source material in workspace/, and percent_change does the arithmetic. CodraftMiddleware adds Codraft's own tools for reading the document and proposing edits, plus its co-author prompt.
    • Instructions through extra_prompt. The middleware appends them to the co-author prompt: take every figure from the tools, say when one is preliminary, draft only the sections asked for, and when a comment corrects a figure, change only what depends on it.
    • A name. create_agent(..., name="Juniper"), so the editor says "Ask Juniper" and "Suggestions from Juniper".

    There's no approval code in the agent. Codraft turns every change the agent proposes into a suggestion on the block, and the author decides.

    gallery/board-update/agent.py
    """Board update co-author: drafts a quarterly update from the numbers, in Codraft.

You write the outline and the ask; the agent drafts the sections from the quarter's
metrics and the operations notes. Everything it writes arrives as a suggestion on the
page, which you accept or reject. When finance corrects a figure, leave a comment and
the agent proposes the edit. A checkpoint ("Sent to finance") lets you see, and export
as a Word redline, exactly what changed since.

Run it in Codraft (from this folder):

    pip install langstage-codraft langchain-anthropic
    export ANTHROPIC_API_KEY=...        # or OPENROUTER_API_KEY=... (pip install langchain-openai)
    langstage-codraft run --agent agent.py:graph

Then make a document with headings for Results and Returns, and ask: "Draft a short
paragraph under Results and one under Returns from the Q3 numbers and the ops notes."
"""

from __future__ import annotations

import json
import os
from pathlib import Path

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain_core.tools import tool
from langstage_codraft import CodraftMiddleware


def make_model():
    """Claude Sonnet 5: through OpenRouter when OPENROUTER_API_KEY is set, else directly."""
    if os.environ.get("OPENROUTER_API_KEY"):
        from langchain_openai import ChatOpenAI

        return ChatOpenAI(
            model="anthropic/claude-sonnet-5",
            base_url="https://openrouter.ai/api/v1",
            api_key=os.environ["OPENROUTER_API_KEY"],
        )
    return init_chat_model("anthropic:claude-sonnet-5")


# The source material sits next to this file, so it works from any directory.
DATA = Path(__file__).resolve().parent / "workspace"


@tool
def read_metrics() -> str:
    """The quarter's metrics as JSON: revenue, orders, returns, NPS, top categories.

    Each figure is given for this quarter and a comparison quarter. A ``note`` on a
    figure says when it is preliminary.
    """
    return (DATA / "metrics.json").read_text(encoding="utf-8")


@tool
def read_ops_notes() -> str:
    """The operations team's notes for this update: what drove the numbers and the fix
    they want the board to approve."""
    return (DATA / "ops-notes.md").read_text(encoding="utf-8")


@tool
def percent_change(old: float, new: float) -> str:
    """The change from ``old`` to ``new`` in percent, rounded to one decimal place."""
    if old == 0:
        return "undefined (old value is 0)"
    return f"{(new - old) / old * 100:+.1f}%"


INSTRUCTIONS = f"""\
You help the founders of {json.loads((DATA / "metrics.json").read_text(encoding="utf-8"))["company"]}
write their quarterly update for the board.

- Take every figure from read_metrics or read_ops_notes, and every percentage change
  from percent_change. Never estimate a number. If a figure is marked preliminary,
  say so in the text.
- The board reads this in five minutes. Short paragraphs, the number first, then what
  it means. No headings of your own, no bullet lists unless asked.
- The authors wrote the outline, the opening and the ask. Draft only the sections you
  are asked for, under the heading they belong to, and leave the authors' paragraphs
  alone unless a comment asks you to change one.
- When a comment corrects a figure, change that figure and any sentence that depends on
  it, and nothing else.
"""

graph = create_agent(
    make_model(),
    tools=[read_metrics, read_ops_notes, percent_change],
    middleware=[CodraftMiddleware(extra_prompt=INSTRUCTIONS)],
    name="Juniper",
)

    Run it yourself¶

    git clone https://github.com/dkedar7/langstage-docs
cd langstage-docs/gallery/board-update
pip install langstage-codraft langchain-anthropic
export ANTHROPIC_API_KEY=...
langstage-codraft run --agent agent.py:graph

    Make a document with a Results and a Returns heading, then ask "Draft a short paragraph under Results and one under Returns from the Q3 numbers and the ops notes." To use OpenRouter instead, set OPENROUTER_API_KEY and pip install langchain-openai.

    The company is fictional: Northwind Outfitters, the same shop as the support triage example, whose cracked tent poles show up here as a quarter's returns. For your own reports, point the reading tools at your metrics store or a spreadsheet export. Suggestions, comments and checkpoints work the same way.

    About this recording¶

    Recorded on 2026-11-27 with Claude Sonnet 5 (through OpenRouter), langstage-codraft 0.12.5 and langstage-core 1.0.70. The run is unscripted: the model chose every tool call and wrote every paragraph. The recorder created the outline through Codraft's REST API before the clip starts, then typed the request, the checkpoint name and the comment. Stretches where the screen is waiting on the model play at 3x. The recorder is demos/gallery/record_board_update.py.
